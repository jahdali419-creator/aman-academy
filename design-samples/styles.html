Three brand styles for Aman Academy

Built from your Wharton Module 4 notes. The module's main point is that brand elements must work in unison, so each style below is shown as a whole: name, logo, one owned colour, tagline, the certificate as packaging, and trust cues.

The name is the anchorEasy to process, meaningful, hard to change later.أمان is a real word that says the benefit. Every style puts the name itself in or beside the mark.
Own one colourTiffany blue, Mary Kay pink. Few brands manage it.Each style commits to a single colour and uses it everywhere, with small dots only to tell courses apart.
People read the picture firstThe Gap logo failed on visuals, not words.The symbol carries the meaning without the text: a shield, a helmet, a seal.
Round beats sharpThe same detergent was rated better in the box with circles.Marks sit in circles and soft shields. No hard triangles.
The package sellsPeople judge the product by its box.Your package is the certificate and the course card, so both are designed with the logo.
Give shortcuts and reasonsCentral route for buyers who think; cues for the rest.Verified-certificate and live-instructor cues are built in. Seat counts appear only when real.

TAGLINES

Four types from the module

Short, differentiated, easy to say, and tested for unwanted meanings in both languages before use.

TypeArabicEnglishNote
Descriptiveمعرفة تحمي، وثقة للتصرفConfidence to act. Knowledge to protect.Your current line. Adds meaning to the name.
Imperativeتعلّم. اختبر. احمِ.Learn it. Prove it. Protect.Three beats that follow the journey: class, exam, real life.
Provocativeجاهز حين يلزم؟Ready when it counts?Makes people think about the moment they will need it.
Superlativeأوضح طريق إلى شهادة سلامةThe clearest path to a safety certificate.Use only if you can back the claim; superlatives invite challenge.
